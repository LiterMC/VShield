## Damage types

All damages to the shield will be classified to either *energy damage* or *kinetic damage*.
A damage source can cause both *energy damage* and *kinetic damage*, but each damage type have to calculate separately.

### Energy

**Source Examples**:
- Fire arrows
- Player / mobs placing block
- Player / mobs trying to enter ship area
- Potion cloud
- Potion projectles
- Spreading fire
- TNT

### Kinetic

**Source Examples**:
- Arrows
- Falling blocks
- Player / mobs breaking block
- TNT
